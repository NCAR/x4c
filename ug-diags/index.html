CESM Diagnostics

x4c.Timeseries indexes a whole post-processed case and gives you variables by name, including derived variables that are computed on demand. The spell notation compresses a processing chain into a single string.

  • The Timeseries case object

  • Loading variables — case.load(vn)

  • The derived-variable registry — variables that are computed rather than read

  • Ocean and land surface state — SST, SSS, MLD, LST

  • Water isotopes — d18Op, dDp, d18Osw, d18Oc

  • Radiation, sea ice, and climate indices — RESTOM, ICEFRAC, DP, NINO3.4

  • The spell mini-language — a processing chain as one string

  • Adding a derived variable — the @F decorator

  • quickview: a diagnostics dashboard in one call

  • Reading CESM logs — x4c.Logs
